MICROSOFT · POWER BI

Consulter le rapport dans Desktop

Cloner le dépôt complet, actualiser les exports R, puis construire le paramètre local :

source("scripts/build_powerbi.R")

Ouvrir powerbi/Observatoire.pbip dans Power BI Desktop et choisir Actualiser. Le générateur réécrit les définitions ; préserver les personnalisations avant relance.
