# Données synthétiques publiables

Ce dossier est réservé aux petits fichiers CSV entièrement synthétiques,
sélectionnés pour accompagner le démonstrateur personnel indépendant de l'UPEC.
Il ne contient actuellement aucune donnée.

Les CSV placés directement ici peuvent être versionnés. Avant tout ajout,
documenter dans ce fichier leur origine synthétique, la graine, la commande de
génération, le schéma, les contrôles réussis et leur finalité de publication.
Ne jamais y déposer de données personnelles réelles, de secrets ni d'exports
d'enquêtes réelles. Le nom du dossier et les règles Git ne prouvent pas le
caractère synthétique d'un fichier : son contenu doit être contrôlé.

Les tables de travail restent dans `data/raw/`, `data/interim/` et
`data/processed/`, dont le contenu est exclu de Git. Les sous-dossiers et les
formats autres que CSV restent également exclus ici.
